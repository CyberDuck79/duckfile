# Duckfile Documentation Site Setup Guide\n\nThis guide explains how to deploy your Jekyll documentation site to GitHub Pages.\n\n## Overview\n\nThe documentation site is built with Jekyll and uses a custom theme with:\n- White background and #08363E accent color (Duckfile brand)\n- Responsive design with sidebar navigation\n- Syntax highlighting for code blocks\n- SEO optimization and social media integration\n- Automated deployment via GitHub Actions\n\n## Files Structure\n\n```\n├── _config.yml              # Jekyll configuration\n├── Gemfile                   # Ruby dependencies\n├── assets/\n│   └── main.scss            # Main stylesheet entry\n├── _sass/\n│   └── duckfile/            # Custom theme styles\n│       ├── _base.scss       # Base styles and typography\n│       ├── _layout.scss     # Layout and navigation\n│       ├── _syntax-highlighting.scss\n│       └── _components.scss # UI components\n├── _layouts/\n│   ├── default.html         # Base layout\n│   └── docs.html           # Documentation page layout\n├── _includes/\n│   ├── head.html           # HTML head section\n│   ├── header.html         # Site header\n│   ├── sidebar.html        # Documentation navigation\n│   ├── footer.html         # Site footer\n│   └── social.html         # Social media links\n├── _docs/                   # Documentation pages\n├── .github/workflows/\n│   └── jekyll.yml          # GitHub Actions deployment\n├── index.md                 # Home page\n└── 404.html                # Error page\n```\n\n## GitHub Pages Deployment\n\n### Step 1: Repository Settings\n\n1. Go to your repository on GitHub: `https://github.com/CyberDuck79/duckfile`\n2. Click on **Settings** tab\n3. Scroll down to **Pages** section in the left sidebar\n4. Under **Source**, select **GitHub Actions**\n\n### Step 2: Automatic Deployment\n\nThe GitHub Actions workflow (`.github/workflows/jekyll.yml`) will automatically:\n- Trigger on pushes to the `main` branch\n- Install Ruby and Jekyll dependencies\n- Build the site\n- Deploy to GitHub Pages\n\n### Step 3: Access Your Site\n\nOnce deployed, your documentation will be available at:\n`https://cyberduck79.github.io/duckfile`\n\n## Local Development\n\n### Prerequisites\n\n- Ruby 3.0+ installed\n- Bundler gem: `gem install bundler`\n\n### Setup\n\n1. Install dependencies:\n   ```bash\n   bundle install\n   ```\n\n2. Serve the site locally:\n   ```bash\n   bundle exec jekyll serve\n   ```\n\n3. Open http://localhost:4000 in your browser\n\n### Live Reload\n\nFor development with live reload:\n```bash\nbundle exec jekyll serve --livereload\n```\n\n## Custom Domain (Future)\n\nWhen you're ready to set up a custom domain:\n\n1. Create a `CNAME` file in the root directory with your domain name\n2. Configure DNS records at your domain provider\n3. Update the `url` in `_config.yml`\n4. Enable HTTPS in GitHub Pages settings\n\n## Content Management\n\n### Adding New Documentation Pages\n\n1. Create markdown files in the `_docs/` directory\n2. Add front matter with layout and metadata:\n   ```yaml\n   ---\n   layout: docs\n   title: Page Title\n   description: Page description\n   ---\n   ```\n3. Update navigation in `_config.yml` under the `navigation` section\n\n### Navigation Structure\n\nThe navigation is defined in `_config.yml` and automatically generates the sidebar. Each section can have children for sub-pages.\n\n### Styling Customization\n\nCustom styles are in `_sass/duckfile/`. The brand color (#08363E) is defined as a variable and used throughout the theme.\n\n## Monitoring and Analytics\n\n### GitHub Actions\n\nMonitor deployment status in the **Actions** tab of your repository. Each commit to `main` triggers a new deployment.\n\n### Adding Analytics (Optional)\n\nTo add Google Analytics:\n1. Add `google_analytics: 'YOUR-GA-ID'` to `_config.yml`\n2. The jekyll-seo-tag plugin will automatically include tracking code\n\n## Troubleshooting\n\n### Build Failures\n\n1. Check the Actions tab for build logs\n2. Common issues:\n   - Ruby version compatibility\n   - Missing dependencies in Gemfile\n   - YAML syntax errors in _config.yml\n   - Liquid template syntax errors\n\n### Local Development Issues\n\n1. Bundle install fails:\n   ```bash\n   bundle update\n   ```\n\n2. Jekyll serve fails:\n   ```bash\n   bundle exec jekyll clean\n   bundle exec jekyll serve\n   ```\n\n## Next Steps\n\nNow that your documentation site is set up:\n\n1. **Start writing content** following the documentation plan\n2. **Test the deployment** by pushing changes to main\n3. **Customize the theme** if needed for branding\n4. **Set up custom domain** when ready\n5. **Add analytics** to track usage\n\n## Support\n\nFor Jekyll-specific issues:\n- [Jekyll Documentation](https://jekyllrb.com/docs/)\n- [GitHub Pages Documentation](https://docs.github.com/en/pages)\n- [GitHub Actions Documentation](https://docs.github.com/en/actions)\n\nFor Duckfile-specific content questions, refer to the codebase and existing documentation structure.
